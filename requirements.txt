# requirements.txt —— 給「不裝 uv」的人用的備援清單。
#
# ⚠ 這個專案的權威是 pyproject.toml ＋ uv.lock，正規裝法是：
#
#       uv sync --extra dev --extra ui
#
#   這份檔案是手寫的鏡像，只列**直接相依**（不含傳遞相依），版本對齊 uv.lock
#   當下解出來的那一組。所以它保證得了「裝起來能跑」，保證不了「五台機器完全
#   一樣」——那件事只有 uv.lock 做得到。
#
#   uv.lock 改過之後這裡要跟著改，或直接重生一份完整的（含傳遞相依）：
#
#       uv export --no-hashes --extra dev --extra ui -o requirements.txt
#
# 用法（Windows）：Python 要 3.11.x，不是 3.12 也不是 3.13
#
#       py -3.11 -m venv .venv
#       .venv\Scripts\activate
#       pip install -r requirements.txt
#
#   沒有 3.11 的話最省事的還是裝 uv：winget install --id astral-sh.uv -e
#   然後 uv python install 3.11——不必自己去官網抓、也不會弄亂系統的 Python。
